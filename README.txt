Group 6 - Predicting Credit Default Risk

Files included:
1. Group6_Credit_Default_Risk_Notebook.ipynb - Complete Jupyter notebook with code, markdown explanations, EDA, visualizations, feature engineering, two classification models, and evaluation.
2. Group6_Credit_Default_Risk_Report.docx - Written report matching the notebook results.
3. Group6_Credit_Default_Risk_Report.pdf - PDF copy of the written report for easy viewing.
4. datasets/creditrisk_applications_final.csv - Main dataset.
5. datasets/creditrisk_inquiries_final.csv - Supplementary inquiry dataset.

How to run:
- Open the notebook in Jupyter Notebook, JupyterLab, or VS Code.
- Keep the datasets folder in the same folder as the notebook.
- Run all cells from top to bottom.
